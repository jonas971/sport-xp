# SportXP 🔥

Une appli Android façon Duolingo pour faire du sport régulièrement :

- **XP, niveaux et série de jours** (avec 1 joker par semaine pour sauver ta série)
- **Séance du jour** à la maison, sans matériel, qui s'adapte à ton niveau, ou **mini séance de 5 min**
- **Créneaux indisponibles fixes** chaque semaine, avec un **mode vacances**
- **Indisponibilités ponctuelles** (rendez-vous, sortie…)
- **Rappels intelligents** : seulement quand tu es libre, de plus en plus insistants

## Télécharger l'APK

Chaque modification du code compile automatiquement l'appli (onglet *Actions*).
La dernière version est dans **Releases** : `SportXP.apk`.

## Sur Xiaomi

Dans l'appli, onglet ⚙️ Réglages → « Important sur Xiaomi » : active le démarrage
automatique et mets l'économiseur de batterie sur « Aucune restriction », sinon les
rappels peuvent être bloqués.
